# 試卷手寫筆跡清除工具技術規格

## 1. 概述

本工具讓使用者用手機拍下或選取試卷圖片，自動移除所有非印刷筆跡，並保留印刷內容。擦除由圖像編輯模型依一段固定 prompt 完成。處理後的頁面可預覽，並下載為 PDF。

允許少量失敗：手寫蓋在印刷圖片上而分不開時，留在圖上；蓋住印刷字而分不開時，保留印刷字，寧可留下少量筆跡。這類頁面仍照常輸出。

## 2. 目標與非目標

### 目標

- 移除手寫字、塗鴉、箭頭、圈選、畫線、螢光筆，以及紅、藍、黑筆和鉛筆。
- 保留印刷題目、選項、頁碼、格線、表格、公式、印刷圖片與線圖。
- 印刷文字保持原圖的繁體或簡體，不轉換、不改字、不新增文字、不重排版面。
- 提供預覽，並可將結果下載為 PDF。
- 支援以手機拍攝或從相簿上傳。

### 非目標

- 不保證像素級還原，也不以遮罩、筆畫骨架或局部修補作為擦除手段。
- 不在手寫無法與印刷圖片或印刷字分離時挖空印刷內容。
- 不把「印刷區 OCR 前後不一致」當成整頁作廢條件。
- 不處理多頁合成為一份已裝訂的原始檔以外的版面重編。每一張上傳圖對應 PDF 的一頁；一次上傳多張時，依上傳順序組成一份 PDF。

## 3. 使用流程

1. 使用者在 App 內啟動文件掃描，或從相簿選擇試卷圖片。
2. 客戶端先做紙張偵測、透視校正與裁切，再上傳。
3. 伺服器校正方向、轉成 JPEG，並把長邊縮到模型可接受的大小。
4. 伺服器將圖與固定 prompt 送交圖像編輯模型，只採用回傳的圖像。
5. App 顯示處理後的預覽。使用者可下載 PDF。
6. 手寫殘留、圖上筆跡未移除，或少量印刷筆畫變化，仍顯示預覽並允許下載。

圖像編輯通常需要數秒到數十秒。上傳後立即返回工作編號，客戶端輪詢狀態，完成後再取預覽與 PDF。

## 4. 固定 Prompt

Prompt 寫死在伺服器，不接受客戶端覆寫。

```text
這是一張試卷掃描。移除所有非印刷筆跡：手寫字、塗鴉、箭頭、圈選、畫線、螢光筆，以及紅、藍、黑筆和鉛筆。

保留全部印刷內容：題目文字、選項、頁碼、格線、表格、公式、印刷圖片與線圖。
文字保持原圖的繁體或簡體，不要轉換，不要改字，不要新增文字，不要重排版面。

手寫若蓋在印刷圖片或線圖上、無法分開，就留在圖上，不要修改那張圖。
手寫若蓋住印刷字或格線、無法分開，保留印刷字和格線，寧可留下少量筆跡，不要挖空印刷內容。

只輸出修改後的圖像。
```

模型若同時回傳文字，捨棄文字，只保存圖像。

## 5. 技術堆疊

| 層級 | 選擇 | 職責 |
|---|---|---|
| App | React Native 0.88 | 文件掃描、相簿選圖、上傳、預覽、下載 PDF |
| 掃描 | iOS VisionKit、Android ML Kit Document Scanner | 紙張偵測、透視校正、裁切 |
| 後端 | Python、FastAPI | 收圖、前處理、呼叫模型、工作狀態、輸出 PDF |
| 擦除 | 千問圖像編輯 `qwen-image-3.0-pro`（中國香港） | 依固定 prompt 產出清除後的頁面圖 |
| PDF | 內嵌 JPEG | 每一頁放一張結果圖，不重新壓縮、不轉成可搜尋文字 |

預設模型為 `qwen-image-3.0-pro`，呼叫中國香港地域。模型名稱放在環境變數。API 金鑰與工作空間編號只放在伺服器，且必須同屬中國香港地域。客戶端不接觸模型。

## 6. 後端行為

### 前處理

- 依 EXIF 轉正。
- 統一編碼為 JPEG。
- 長邊超過模型輸入上限時等比縮小。縮小只為了符合 API 限制，不做去字或修補。
- 單張上傳圖對應一次模型呼叫。

### 工作

| 方法 | 路徑 | 行為 |
|---|---|---|
| `POST` | `/jobs` | 以 `multipart/form-data` 上傳一張或多張頁面圖，建立工作並回傳工作編號 |
| `GET` | `/jobs/{id}` | 回傳狀態：`pending`、`running`、`succeeded`、`failed` |
| `GET` | `/jobs/{id}/preview` | 成功後回傳各頁結果圖 |
| `GET` | `/jobs/{id}/pdf` | 成功後回傳 PDF |

狀態為 `failed` 時回傳可顯示的錯誤，例如模型拒絕、逾時或輸出中沒有圖像。不把「仍有手寫殘留」標成失敗。

### PDF

- 一頁結果圖成為 PDF 的一頁。
- 頁面順序與上傳順序相同。
- 不重新排版題目，不把圖轉成可搜尋文字。

### 檔案生命週期

試卷可能含姓名、學號與分數。原圖、結果圖與 PDF 在工作完成並被下載，或超過保留時間後刪除。保留時間的預設值為 24 小時。伺服器記錄不寫入試卷影像內容。

## 7. App 行為

- 掃描與相簿匯入都走系統文件掃描，不另做一套裁切介面。
- 上傳中顯示處理狀態，完成後顯示每一頁的預覽。
- 預覽不阻擋下載。使用者可在仍有殘留筆跡時下載 PDF。
- PDF 經系統分享表輸出。
- 無網路或工作失敗時顯示錯誤，並保留使用者手上的原圖。

## 8. 驗收

上線前用真卷各準備繁體與簡體樣本，且樣本須包含：

- 寫在空白與格線上的手寫字、塗鴉、箭頭與圈選
- 紅筆、藍筆與鉛筆
- 印刷圖片，以及寫在圖片上的筆跡
- 寫在印刷題目上的筆跡

通過條件：

- 空白與格線上的非印刷筆跡大多數已移除。
- 印刷圖片仍在；圖上分不開的筆跡可以留下。
- 題目沒有整段消失、明顯改寫或繁簡轉換。少量筆畫誤差可接受。
- 每一張成功的模型回應都能預覽並下載 PDF。
- 模型失敗時工作為 `failed`，且不會把原圖當成清除結果。

## 9. 已知限制

- Prompt 不能鎖住個別像素。模型可能微調字距、比例，或改動個別中文筆畫。
- 輸出會重繪。請求的像素面積維持原頁比例，並落在模型允許的範圍內。
- 寫在印刷圖片或線圖上的筆跡，依 prompt 可以保留。
- 單頁費用隨圖像輸出計價。一次工作的頁數應設上限，預設 20 頁。
